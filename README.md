# Iris Flower Classification

## Project Overview
This beginner-friendly machine learning project predicts the species of an Iris flower from its sepal and petal measurements.

## Dataset
The built-in Iris dataset from scikit-learn.

## Machine Learning Models
- Logistic Regression
- Support Vector Machine (SVM)

## Results

| Model | Test Accuracy |
|---|---:|
| Logistic Regression | 93.33% |
| SVM | 100% |

These results are based on one train-test split and do not guarantee the same performance on unseen datasets.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## How to Run
Open `iris_classification.ipynb` in Google Colab and run the cells in order.
